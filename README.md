# Preventa Distribuidores del Castillo — PWA
Subí estos archivos a GitHub y activá GitHub Pages. Abrí la URL resultante en Chrome Android y elegí **Instalar aplicación** / **Agregar a pantalla principal**.
Incluye dashboard, clientes, preventa Unidad/Docena/Caja, descuentos, pedidos en firme, historial, consolidado/picking, productos y almacenamiento local.
